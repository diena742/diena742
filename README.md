## 🧑‍💻 About Me

> *"The best automation is the one you forget is running."*

Saya adalah developer yang obsesif terhadap **efisiensi, otomatisasi, dan eksplorasi batas sistem**. Saya percaya bahwa perangkat Android yang tepat — dengan tools yang tepat — bisa menjadi workstation yang lebih powerful dari yang kebanyakan orang bayangkan.

```bash
$ whoami
> Full-stack Developer · Automation Engineer · Android System Enthusiast
```

- 🎬 **Cineverse** — Ekosistem streaming drama pendek dengan integrasi API kustom & automated content pipeline
- 🤖 **Automation First** — Dari scraping hingga video processing, saya mengotomatisasi apa pun yang berulang
- 📱 **Android Internals** — Kernel optimization (Poco F1/F3), **KernelSU**, **Shizuku**, dan Android shell scripting tingkat lanjut
- 🌐 **Networking** — WISP / Multi-WAN setup untuk stabilitas server lokal
